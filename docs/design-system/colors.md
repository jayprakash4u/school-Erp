# Colors & Semantic Color Tokens

## 1. Brand Identity Colors

| Token | Hex | Role & Usage |
| :--- | :--- | :--- |
| `brand-primary` | `#DC2626` | Primary actions, active navigation states |
| `brand-primary-hover` | `#B91C1C` | Hover state for primary action items |
| `brand-primary-active` | `#991B1B` | Pressed state |
| `brand-secondary` | `#111111` | Sidebar navigation, strong contrast |
| `brand-accent` | `#FACC15` | Accent highlights, secondary indicators |

# School ERP Design System v1

The School ERP Design System is an enterprise-grade, accessible, token-driven visual framework tailored for multi-tenant educational institutions, administrators, teachers, parents, and students.

---

## Core Principles

1. **Clear over decorative**: Information density with exceptional clarity.
2. **Consistent over clever**: Predictable component behavior across all modules.
3. **Dense enough for ERP work, but never cramped**: Standardized 4px spacing unit with generous line heights.
4. **Accessibility first**: High-contrast ratios and focus states.
5. **Semantic colors**: Never hardcode colors; use semantic CSS tokens (`--color-brand-primary`, `--color-form-border`, etc.).
6. **Reusable components**: Built from atomic UI primitives.
7. **Mobile-friendly foundations**: Seamless degradation from 1536px desktop down to mobile viewports.
8. **Avoid arbitrary values**: Stick to established scales for spacing, radius, typography, and shadows.

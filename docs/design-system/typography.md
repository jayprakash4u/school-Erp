# Typography System

## Primary Font
- **Family**: `Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, sans-serif`
- **Weights**: `400` (Regular), `500` (Medium), `600` (Semibold), `700` (Bold)

---

## Typography Scale

| Name | Size / Line Height | Weight | Tailwind Utility | Role / Usage |
| :--- | :--- | :--- | :--- | :--- |
| `display-xl` | 36px / 44px | 700 | `text-display-xl` | Landing / Hero headline |
| `display-lg` | 32px / 40px | 700 | `text-display-lg` | Big overview displays |
| `heading-xl` | 28px / 36px | 700 | `text-heading-xl` | Major module titles, large metrics |
| `heading-lg` | 24px / 32px | 700 | `text-heading-lg` | Page headers (`h1`) |
| `heading-md` | 20px / 28px | 600 | `text-heading-md` | Card section titles (`h2`) |
| `heading-sm` | 18px / 26px | 600 | `text-heading-sm` | Modal titles, subsection headers (`h3`) |
| `body-lg` | 16px / 24px | 400 | `text-body-lg` | Large body text, introductory paragraphs |
| `body-md` | 14px / 20px | 400 | `text-body-md` | **Workhorse size** for ERP forms, table rows |
| `body-sm` | 13px / 18px | 400 | `text-body-sm` | Secondary table cells, helper descriptions |
| `label` | 14px / 20px | 500 | `text-label` | Form labels, input identifiers |
| `caption` | 12px / 16px | 400 | `text-caption` | Timestamp metadata, footnotes |
| `overline` | 11px / 16px | 600 | `text-overline` | Table headers, category uppercase tags |

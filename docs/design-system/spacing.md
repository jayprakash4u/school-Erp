# Spacing System

Based on a strict **4px base unit**.

| Token | Value | Primary Usage |
| :--- | :--- | :--- |
| `space-0` | `0px` | Reset |
| `space-1` | `4px` | Fine adjustments, dot indicators |
| `space-2` | `8px` | Gap between label & input, badge padding |
| `space-3` | `12px` | Compact button padding, dropdown gap |
| `space-4` | `16px` | Standard table cell padding, card inner spacing |
| `space-5` | `20px` | Dialog padding, table header padding |
| `space-6` | `24px` | Section margins, card padding |
| `space-8` | `32px` | Page content margins |
| `space-10` | `40px` | Major section breaks |
| `space-12` | `48px` | Large container gutters |
| `space-16` | `64px` | Layout structural gaps |
| `space-20` | `80px` | Hero section padding |
| `space-24` | `96px` | Full page breaks |

### Core Working Sizes:
`8px`, `12px`, `16px`, `24px`, `32px`.

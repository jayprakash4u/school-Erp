# Border Radius & Shadows

## Border Radius Scale

| Token | Value | Target Components |
| :--- | :--- | :--- |
| `radius-none` | `0px` | Full width banners, tables |
| `radius-sm` | `4px` | Checkboxes, tooltips, sub-badges |
| `radius-md` | `6px` | **Buttons, Form Inputs, Selects** |
| `radius-lg` | `8px` | **Cards, Panels, Container Boxes** |
| `radius-xl` | `12px` | **Modals, Drawers** |
| `radius-2xl` | `16px` | Large floating dialogs |
| `radius-full` | `9999px` | **Badges, Avatars, Status Pills** |

---

## Shadow Tokens

| Token | Value | Target Components |
| :--- | :--- | :--- |
| `shadow-none` | `none` | Standard Cards & Tables (rely on borders) |
| `shadow-sm` | `0 1px 2px rgba(0,0,0,0.05)` | Light button elevations |
| `shadow-md` | `0 4px 6px rgba(0,0,0,0.08)` | Dropdowns, Popovers, Tooltips |
| `shadow-lg` | `0 10px 15px rgba(0,0,0,0.10)` | Toasts, Hover cards |
| `shadow-xl` | `0 20px 25px rgba(0,0,0,0.12)` | Modals, Slide-over Drawers |
